# PMS Android

Open-source Android client for Personal Music Streaming.

## Project status

Initial Android scaffold with a minimal Jetpack Compose screen and automated APK builds.

## Technology

- Kotlin
- Jetpack Compose
- AndroidX Media3 (planned playback engine)
- Navidrome-compatible Subsonic API

## Build

GitHub Actions builds a debug APK on every push to `main`. You can also start a build manually from the Actions tab.
